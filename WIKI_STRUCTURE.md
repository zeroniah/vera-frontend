### 2. Citation-Guide

```markdown
# How to Cite VERA Tokens

Every VERA token page includes a built-in citation generator with multiple academic formats.

## Supported Formats

- **APA 7th Edition** - Psychology, Education, Social Sciences
- **BibTeX** - LaTeX documents, technical papers
- **MLA 9th Edition** - Humanities, Literature
- **Chicago 17th Edition** - History, Fine Arts

## Quick Citation Steps

1. Navigate to the token detail page
2. Scroll to "Citation Generator" section
3. Select your preferred format from tabs
4. Click **"Copy Citation"** button
5. Paste into your bibliography

## Example Citations

**APA Format:**
```
Zeroniah Research Collective. (2026). VERA-M045-20260101: Mitochondrial Biogenesis Validation Token. VitalGnosis VERA System. Retrieved from https://vera-tokens.vercel.app/vera?token=VERA-M045-20260101
```

**BibTeX Format:**
```bibtex
@misc{VERA-M045-20260101,
  author = {{Zeroniah Research Collective}},
  title = {VERA-M045-20260101: Mitochondrial Biogenesis Validation Token},
  year = {2026},
  publisher = {VitalGnosis VERA System},
  url = {https://vera-tokens.vercel.app/vera?token=VERA-M045-20260101}
}
```

## Download Options

- **Copy to Clipboard** - One-click citation copy
- **Download .bib File** - Import directly into reference managers (Zotero, Mendeley, EndNote)

## Citation Best Practices

1. **Always include the full token ID** (e.g., VERA-M045-20260101)
2. **Link to the token page** - Enables verification and reproducibility
3. **Note the access date** - Research validation evolves over time
4. **Check for updates** - Token confidence scores may change with new evidence

## Reference Manager Integration

**Zotero:**
1. Copy BibTeX citation
2. File → Import from Clipboard

**Mendeley:**
1. Download .bib file
2. File → Import → BibTeX

**EndNote:**
1. Copy citation text
2. References → New Reference → Manual Entry
```

### 4. Token-Metrics-Guide

```markdown
# Understanding Token Metrics

Each VERA token displays key validation metrics. Here's what they mean.

## Confidence Percentage

**Range:** 0-100%

Represents the overall confidence in the research claim based on:
- Reproducibility success rate
- Peer review consensus
- Methodological rigor score
- Cross-validation with related research

**Interpretation:**
- **90-100%:** High confidence - Strong evidence, multiple validations
- **70-89%:** Moderate confidence - Good evidence, some limitations
- **50-69%:** Low confidence - Preliminary evidence, requires further validation
- **Below 50%:** Weak confidence - Insufficient evidence or conflicting results

## VERA Staked

**Unit:** VERA tokens

The amount of VERA cryptocurrency staked by validators who endorse this research claim.

**Why it matters:**
- Higher stakes = Validators risking more capital on correctness
- Economic incentive for validators to verify thoroughly
- Slashing mechanism penalizes false endorsements

## Status

**Possible Values:**
- **Active** - Currently validated and available for citation
- **Under Review** - New counterevidence being evaluated
- **Challenged** - Reproducibility issues reported
- **Deprecated** - Superseded by updated research

## Reproducibility Score

**Range:** 0-100 points

Measures how successfully others have reproduced the research:
- Independent replication attempts
- Code execution success rate
- Data availability quality
- Protocol clarity score

**Components:**
- **Replication Rate (40%)** - Success rate of independent replications
- **Code Quality (30%)** - Automated tests, documentation, dependencies
- **Data Accessibility (20%)** - FAIR principles compliance
- **Protocol Clarity (10%)** - Procedural detail and unambiguity

## Related Tokens

Number of other VERA tokens in the same research domain that cite or relate to this work.

**Network Effect:** Tokens with many related validations have stronger ecosystem support.

### 6. Troubleshooting

```markdown
# Troubleshooting & FAQ

Common issues and solutions for VERA token pages.

## Token Page Won't Load

**Symptoms:** Blank page or "Token Not Found" error

**Solutions:**
1. Check token ID format: `VERA-M045-20260101`
2. Verify URL structure: `?token=` parameter present
3. Try refreshing with Ctrl+F5 (hard refresh)
4. Check backend status: https://backend.vitalgnosis.com/health

## Citation Copy Button Not Working

**Symptoms:** Click "Copy Citation" but nothing happens

**Solutions:**
1. Ensure browser allows clipboard access (check permissions)
2. Manually select and copy text if button fails
3. Try different browser (Chrome, Firefox, Edge all supported)

## Reproducibility Request Form Fails

**Symptoms:** "Error submitting request" message

**Solutions:**
1. Check all required fields are filled
2. Verify email format is valid
3. Ensure purpose description is 50+ characters
4. Try again after 5 minutes (rate limiting)

## Related Tokens Not Displaying

**Symptoms:** "Related Tokens" section is empty

**Solutions:**
- May indicate this is the only token in its subdomain
- Check back after more tokens are published
- Not a bug - some research is genuinely unique

## Page Loads Slowly

**Symptoms:** Long wait time before content appears

**Solutions:**
1. Check internet connection speed
2. Try different time of day (peak hours may slow API)
3. Use Vercel's edge network (automatic if accessing from `vera-tokens.vercel.app`)
4. Clear browser cache

## Citation Format Missing

**Symptoms:** Only seeing APA, but need Chicago

**Solutions:**
- All 4 formats should be available via tabs
- If missing, the token metadata may need updating
- Request specific format via support@vitalgnosis.com

## Can't Download Reproducibility Package

**Symptoms:** Request approved but download link doesn't work

**Solutions:**
1. Check email spam folder for approval notification
2. Download link expires after 7 days - request new link
3. Ensure using same email address as request
4. Contact reproducibility@vitalgnosis.com with token ID

## Mobile Display Issues

**Symptoms:** Page layout broken on smartphone

**Solutions:**
- Page is optimized for mobile (320px+)
- Try rotating to portrait mode
- Update browser to latest version
- Report specific device/browser combo if issue persists

## Contact Support

For issues not covered here:
- **Email:** support@vitalgnosis.com
- **Response Time:** 24-48 hours
- **Include:** Token ID, browser version, screenshot if applicable
```
